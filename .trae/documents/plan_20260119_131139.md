# 每日一字应用新用户初始化配置方案

## 1. 问题分析

* **现象**：全新用户进入每日一字小程序时，

  * 进测试页会提示没有数据

  * 进设置窗口时，难度设置四个按钮都是没有选中的状态

* **原因**：

  1. 首次进入时没有本地配置，且初始化逻辑存在问题
  2. 之前将字卡难度的初始状态从`true`改为`false`，导致新用户进来时四个难度都未选中
  3. 没有在首次进入时将默认配置保存到本地存储
  4. 测试页没有数据可能是因为没有选中任何难度，导致没有过滤出符合条件的字卡

## 2. 解决方案

* **修改文件**：`subgames/daily-character/index.js`

* **修改思路**：

  1. 确保新用户首次进入时，字卡难度设置四个选项默认都选中
  2. 确保测试难度默认设置为"均衡"
  3. 在首次进入时将默认配置保存到本地存储
  4. 确保`onLoad`方法中的初始化逻辑正确处理没有本地配置的情况

* **具体修改**：

  ### 2.1 修改`onLoad`方法中的初始状态

  * **文件位置**：`index.js`中的`onLoad`方法

  * **修改内容**：

    1. 将字卡难度的初始状态从`false`改为`true`，确保默认全选
    2. 确保在没有本地配置时，将默认的全选状态保存到本地存储

  ### 2.2 确保测试难度默认设置为"均衡"

  * **文件位置**：`index.js`中的`onLoad`方法

  * **修改内容**：

    1. 确保测试难度的默认值为"均衡"
    2. 在没有本地配置时，将默认的"均衡"状态保存到本地存储

  ### 2.3 优化初始化逻辑

  * **文件位置**：`index.js`中的`onLoad`方法

  * **修改内容**：

    1. 优化`onLoad`方法中的初始化逻辑
    2. 确保在各种情况下都能正确初始化配置
    3. 确保默认配置能正确保存到本地存储

## 3. 实施步骤

### 3.1 修改`onLoad`方法中的初始状态

1. 打开`index.js`文件
2. 找到`onLoad`方法
3. 将字卡难度的初始状态从`false`改为`true`

### 3.2 优化初始化逻辑

1. 确保在没有本地配置时，将默认的全选状态保存到本地存储
2. 确保测试难度的默认值为"均衡"
3. 确保默认配置能正确保存到本地存储

### 3.3 验证修改效果

1. 清除本地存储，模拟新用户首次进入
2. 进入小程序，检查设置页面的难度设置是否默认全选
3. 检查测试难度是否默认设置为"均衡"
4. 检查本地存储是否保存了默认配置
5. 进入测试页，检查是否有数据

## 4. 预期效果

* 全新用户首次进入每日一字小程序时：

  * 字卡难度设置四个选项默认都选中

  * 测试难度默认设置为"均衡"

  * 这些默认配置会被保存到本地存储

  * 进入测试页时，能看到符合条件的数据

* 已有用户进入小程序时：

  * 继续使用之前保存的配置

  * 不受默认配置的影响

## 5. 风险评估

* **低风险**：仅修改初始化逻辑，不影响核心功能

* **低风险**：修改内容简单，容易恢复

* **无风险**：修改后的功能符合用户预期，提高了新用户的体验

## 6. 实施代码

### 6.1 修改`onLoad`方法中的初始状态

```javascript
// 初始状态：默认四个难度都选中
let difficultyBeginner = true;
let difficultyIntermediate = true;
let difficultyAdvanced = true;
let difficultyChallenge = true;
```

### 6.2 优化初始化逻辑

```javascript
// 读取上次选择的难度模式
const savedDifficulties = wx.getStorageSync('dailyCharacterDifficulties');

// 初始状态：默认四个难度都选中
let difficultyBeginner = true;
let difficultyIntermediate = true;
let difficultyAdvanced = true;
let difficultyChallenge = true;

if (savedDifficulties && typeof savedDifficulties === 'object') {
  // 如果是新的对象格式，直接使用
  if (savedDifficulties.difficultyBeginner !== undefined) {
    difficultyBeginner = savedDifficulties.difficultyBeginner;
    difficultyIntermediate = savedDifficulties.difficultyIntermediate;
    difficultyAdvanced = savedDifficulties.difficultyAdvanced;
    difficultyChallenge = savedDifficulties.difficultyChallenge;
  } 
  // 如果是旧的数组格式，转换为新格式
  else if (Array.isArray(savedDifficulties)) {
    difficultyBeginner = savedDifficulties.includes('初级');
    difficultyIntermediate = savedDifficulties.includes('中级');
    difficultyAdvanced = savedDifficulties.includes('高级');
    difficultyChallenge = savedDifficulties.includes('挑战级');
    
    // 保存为新格式
    wx.setStorageSync('dailyCharacterDifficulties', {
      difficultyBeginner,
      difficultyIntermediate,
      difficultyAdvanced,
      difficultyChallenge
    });
  }
  // 如果是一个空对象或不包含必要属性的对象，使用默认值并保存
  else {
    // 使用默认值并保存到本地存储
    wx.setStorageSync('dailyCharacterDifficulties', {
      difficultyBeginner,
      difficultyIntermediate,
      difficultyAdvanced,
      difficultyChallenge
    });
  }
} else {
  // 无本地存储，使用默认值并保存
  wx.setStorageSync('dailyCharacterDifficulties', {
    difficultyBeginner,
    difficultyIntermediate,
    difficultyAdvanced,
    difficultyChallenge
  });
}

// 读取测试难度设置
const savedTestDifficulty = wx.getStorageSync('dailyCharacterTestDifficulty');
const testDifficulty = savedTestDifficulty || '均衡';

// 确保测试难度设置被保存
if (!savedTestDifficulty) {
  wx.setStorageSync('dailyCharacterTestDifficulty', testDifficulty);
}
```

通过这个方案，我们将确保新用户首次进入每日一字小程序时，字卡难度设置四个选项默认都选中，测试难度默认设置为"均衡"，并将这些默认配置保存到本地存储，解决了新用户进测试页提示没有数据和设置窗口难度未选中的问题。
