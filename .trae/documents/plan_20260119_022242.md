# 每日一字应用设置页面优化方案

## 1. 问题分析

* **现象**：首次进入设置页面时，显示的是默认设置状态（全部难度级别都选中），而后设置后，再次进入就会读取上次设置状态，显示正常

* **原因**：

  * 在 `onLoad` 方法中，当 `savedDifficulties` 是一个空对象 `{}` 时，条件 `if (savedDifficulties && typeof savedDifficulties === 'object')` 会成立

  * 但 `savedDifficulties.difficultyBeginner` 会是 `undefined`，所以会跳过第一个 `if` 分支

  * 然后会检查 `else if (Array.isArray(savedDifficulties))`，但空对象不是数组，所以也会跳过

  * 导致不会执行任何赋值操作，最后使用默认值 `true`

  * 这就是首次进入设置页面显示默认值的原因

## 2. 解决方案

* **修改文件**：`/Users/joshua/Documents/GitHub/Chinesetraditional-miniprogram/subgames/daily-character/index.js`

* **修改思路**：修改 `onLoad` 方法中的条件判断逻辑，确保当 `savedDifficulties` 是一个对象但不包含必要属性时，也能正确处理

* **具体修改**：

  1. 修改 `onLoad` 方法中的条件判断，确保只有当 `savedDifficulties` 包含 `difficultyBeginner` 属性时，才使用本地存储的值
  2. 当 `savedDifficulties` 是一个对象但不包含必要属性时，使用默认值并保存到本地存储
  3. 确保 `tempDifficulties` 始终与 `difficultyBeginner` 等变量保持一致

  * 当本地存储不存在时，使用默认值并保存到本地存储

  * 当本地存储是一个空对象时，使用默认值并保存到本地存储

  * 当本地存储是一个包含必要属性的对象时，使用本地存储的值

  * 当本地存储是一个数组时，转换为新格式并保存到本地存储

## 4. 预期效果

* 首次进入设置页面时，直接显示正确的设置状态（本地存储值或默认值）

* 避免设置页面打开时的视觉闪烁

* 确保所有设置状态（包括难度选择和测试难度）始终保持同步

* 提高用户体验，让用户感受到设置状态的连续性

## 6. 实施代码

### 6.1 修改 `onLoad` 方法

```javascript
// 读取上次选择的难度模式
const savedDifficulties = wx.getStorageSync('dailyCharacterDifficulties');

// 初始状态：默认四个难度都选中
let difficultyBeginner = true;
let difficultyIntermediate = true;
let difficultyAdvanced = true;
let difficultyChallenge = true;

// 检查是否有有效的本地存储
if (savedDifficulties && typeof savedDifficulties === 'object') {
  // 如果是新的对象格式，且包含必要属性，直接使用
  if (savedDifficulties.difficultyBeginner !== undefined) {
    difficultyBeginner = savedDifficulties.difficultyBeginner || true;
    difficultyIntermediate = savedDifficulties.difficultyIntermediate || true;
    difficultyAdvanced = savedDifficulties.difficultyAdvanced || true;
    difficultyChallenge = savedDifficulties.difficultyChallenge || true;
  } 
  // 如果是旧的数组格式，转换为新格式
  else if (Array.isArray(savedDifficulties)) {
    difficultyBeginner = savedDifficulties.includes('初级');
    difficultyIntermediate = savedDifficulties.includes('中级');
    difficultyAdvanced = savedDifficulties.includes('高级');
    difficultyChallenge = savedDifficulties.includes('挑战级');
    
    // 保存为新格式
    wx.setStorageSync('dailyCharacterDifficulties', {
      difficultyBeginner,
      difficultyIntermediate,
      difficultyAdvanced,
      difficultyChallenge
    });
  }
  // 如果是一个空对象或不包含必要属性的对象，使用默认值并保存
  else {
    // 保存默认值到本地存储
    wx.setStorageSync('dailyCharacterDifficulties', {
      difficultyBeginner,
      difficultyIntermediate,
      difficultyAdvanced,
      difficultyChallenge
    });
  }
} else {
  // 无本地存储，使用默认值
  // 保存默认值到本地存储
  wx.setStorageSync('dailyCharacterDifficulties', {
    difficultyBeginner,
    difficultyIntermediate,
    difficultyAdvanced,
    difficultyChallenge
  });
}
```
