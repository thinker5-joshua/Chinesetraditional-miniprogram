# 每日一字缓存机制升级方案

## 一、当前缓存机制分析

### 1. 缓存类型
- **内存缓存**：应用运行时内存中存储
- **磁盘缓存**：使用微信小程序本地存储（wx.setStorageSync）

### 2. 缓存键和过期时间
- 数据缓存键：`daily_character_cache`，过期时间24小时
- 序列缓存键：`daily_character_sequence_cache`，过期时间24小时

### 3. 缓存验证逻辑
- `isCacheValid()` 方法检查缓存是否有效，验证：
  - 缓存数据是否存在且为数组
  - 缓存是否在有效期内（24小时）
- 预加载数据时的缓存检查：
  1. 检查内存缓存，比较云端数据数量
  2. 检查磁盘缓存，比较云端数据数量
  3. 否则从云端获取全量数据

### 4. 当前机制的问题
- **基于数量对比**：仅通过数据数量判断，无法检测内容修改
- **固定过期时间**：缓存24小时后强制失效
- **全量更新**：每次更新需重新获取所有数据
- **无法检测单条数据修改**：部分数据修改仍需加载全部数据

## 二、基于最后修改时间的缓存更新方案

### 1. 方案概述
- 在云数据库中添加最后修改时间记录
- 本地缓存存储该最后修改时间
- 每次启动时比较云端和本地的最后修改时间
- 若不同则更新缓存，相同则使用现有缓存

### 2. 实现步骤

#### 2.1 云数据库改造
**方案B（推荐）**：创建配置表记录整体修改时间
- 创建 `daily_character_config` 表，包含字段：
  - `_id`: 主键
  - `lastModified`: 字库最后修改时间
  - `version`: 字库版本号（可选）
  - `totalCount`: 数据总量（可选）
- 优点：获取最后修改时间高效，只需查询一条记录
- 适用场景：关注整体数据是否更新，对性能要求较高

#### 2.2 缓存结构改造
- 扩展缓存数据结构，添加 `lastModified` 字段
- 缓存键保持不变：`daily_character_cache`

#### 2.3 核心代码修改

**新增方法**：
```javascript
// 获取云端最后修改时间
getCloudLastModified()
// 检查最后修改时间是否变化
isLastModifiedChanged()
```

**修改方法**：
- `isCacheValid()`: 保留基础验证，最后修改时间对比单独处理
- `saveCache()`: 添加 `lastModified` 参数，保存最后修改时间
- `preloadData()`: 修改缓存检查逻辑，基于最后修改时间判断

#### 2.4 完整流程
1. 应用启动，调用 `preloadData()`
2. 调用 `isLastModifiedChanged()` 比较云端和本地最后修改时间
3. 如果时间相同：
   - 使用内存缓存（如果存在）
   - 否则使用磁盘缓存（如果存在且有效）
4. 如果时间不同：
   - 从云端获取全量数据
   - 获取最新的最后修改时间
   - 更新内存缓存和磁盘缓存

## 三、详细代码实现

### 1. 新增方法实现

```javascript
/**
 * 获取云端数据最后修改时间
 * @returns {Promise<number>} 最后修改时间（时间戳）
 */
async getCloudLastModified() {
  if (!await this.init()) {
    return 0;
  }
  try {
    // 优先从配置表获取
    const configCollection = wx.cloud.database().collection('daily_character_config');
    const configResult = await configCollection.orderBy('lastModified', 'desc').limit(1).get();
    if (configResult.data && configResult.data.length > 0) {
      return new Date(configResult.data[0].lastModified).getTime();
    }
    
    // 备选方案：从数据中获取最新修改时间
    const dataResult = await this.collection.orderBy('lastModified', 'desc').limit(1).get();
    if (dataResult.data && dataResult.data.length > 0) {
      return new Date(dataResult.data[0].lastModified).getTime();
    }
    
    return 0;
  } catch (error) {
    console.error('获取云端最后修改时间失败:', error);
    return 0;
  }
}

/**
 * 检查最后修改时间是否变化
 * @returns {Promise<boolean>} 是否变化
 */
async isLastModifiedChanged() {
  const cloudLastModified = await this.getCloudLastModified();
  if (cloudLastModified === 0) {
    return true; // 无法获取云端时间，默认需要更新
  }
  
  // 检查内存缓存
  if (this.memoryCache && this.memoryCacheLastModified === cloudLastModified) {
    return false;
  }
  
  // 检查磁盘缓存
  try {
    const cacheData = wx.getStorageSync(CACHE_KEY);
    if (cacheData && cacheData.lastModified === cloudLastModified) {
      return false;
    }
  } catch (error) {
    console.error('检查磁盘缓存最后修改时间失败:', error);
  }
  
  return true;
}
```

### 2. 修改现有方法

```javascript
/**
 * 保存缓存
 * @param {Array} data 要缓存的数据
 * @param {number} lastModified 最后修改时间
 */
saveCache(data, lastModified) {
  try {
    // 数据验证逻辑...
    
    // 保存到缓存，添加lastModified字段
    const cacheData = {
      data: data,
      timestamp: Date.now(),
      count: data.length,
      validated: true,
      validationTime: Date.now(),
      lastModified: lastModified // 新增：保存最后修改时间
    };
    
    wx.setStorageSync(CACHE_KEY, cacheData);
    // 更新内存缓存...
    
    console.log('缓存保存成功，共', data.length, '条数据，最后修改时间:', lastModified);
  } catch (error) {
    console.error('保存缓存失败:', error);
  }
}

/**
 * 预加载全量数据
 * @returns {Promise<Array>} 全量数据
 */
async preloadData() {
  // 1. 检查最后修改时间是否变化
  const isModified = await this.isLastModifiedChanged();
  if (!isModified) {
    // 最后修改时间未变化，使用缓存
    if (this.memoryCache && this.memoryCache.length > 0) {
      return this.memoryCache;
    }
    
    try {
      const cacheData = wx.getStorageSync(CACHE_KEY);
      if (cacheData && cacheData.data && cacheData.data.length > 0) {
        // 更新内存缓存
        this.memoryCache = cacheData.data;
        this.memoryCacheTimestamp = Date.now();
        this.memoryCacheLastModified = cacheData.lastModified;
        
        return cacheData.data;
      }
    } catch (error) {
      console.error('读取磁盘缓存失败:', error);
    }
  }
  
  // 最后修改时间已变化，从云端获取数据
  try {
    // 获取全量数据...
    
    // 获取最后修改时间
    const lastModified = await this.getCloudLastModified();
    
    // 保存到缓存
    this.saveCache(data, lastModified);
    
    return data;
  } catch (error) {
    console.error('数据预加载失败:', error);
    return [];
  }
}
```

## 四、数据更新机制

1. **手动更新**：每次修改云数据库数据时，更新 `lastModified` 字段
2. **自动更新**：通过云函数触发器实现自动更新
3. **定时更新**：设置定时任务，定期检查并更新 `lastModified` 字段

## 五、兼容性处理

1. **旧缓存兼容**：
   - 读取缓存时，若没有 `lastModified` 字段，视为需要更新
   - 确保新缓存结构向后兼容

2. **异常处理**：
   - 网络异常时，仍可使用现有缓存
   - 获取最后修改时间失败时，降级为基于数量的对比

## 六、方案优势

1. **精确更新**：只有数据真正修改时才更新缓存
2. **性能优化**：减少不必要的数据传输和处理
3. **节省流量**：避免不必要的数据下载
4. **实时性**：数据修改后，下次启动即可获取最新数据
5. **灵活性**：可根据需求调整更新策略
6. **扩展性**：方便扩展为增量更新
