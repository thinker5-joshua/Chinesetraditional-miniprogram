# 每日一字应用设置功能优化方案

## 1. 问题分析

* **现象**：测试难度设置功能正常，但字卡难度首次进入时显示不正确

* **原因**：

  * 字卡难度的记录和存储可能存在两种模式

  * `tempDifficulties` 可能是旧的模式，`savedDifficulties` 是新的读取和保存方式

  * 两种模式共存导致设置读取和保存不一致

  * 首次进入设置页面时，`tempDifficulties` 可能没有正确从本地存储读取设置

## 2. 解决方案

* **修改文件**：`/Users/joshua/Documents/GitHub/Chinesetraditional-miniprogram/subgames/daily-character/index.js`

* **修改思路**：

  * 移除 `tempDifficulties` 临时变量，完全采用直接操作实际设置变量的方式

  * 简化设置流程，避免临时变量导致的不一致性

  * 确保所有设置都从本地存储中正确读取，并保存到本地存储

  * 统一设置的读取和保存逻辑

* **具体修改**：

  ### 2.1 移除 `tempDifficulties` 相关代码

  * 从 `data` 中移除 `tempDifficulties` 变量

  * 移除所有使用 `tempDifficulties` 的代码

  * 直接使用 `difficultyBeginner` 等实际设置变量

  ### 2.2 修改设置窗口的渲染逻辑

  * 修改 WXML 中绑定的变量，从 `tempDifficulties` 改为直接使用 `difficultyBeginner` 等变量

  * 修改难度选择的事件处理函数，直接更新 `difficultyBeginner` 等变量

  ### 2.3 简化设置保存逻辑

  * 移除 `saveSettings` 方法中从 `tempDifficulties` 读取数据的代码

  * 直接从 `difficultyBeginner` 等变量读取设置并保存到本地存储

  ### 2.4 优化 `openSettings` 方法

  * 移除 `openSettings` 方法中初始化 `tempDifficulties` 的代码

  * 简化 `openSettings` 方法，仅显示设置窗口

  ### 2.5 确保设置的一致性

  * 确保在所有情况下，设置变量都从本地存储正确读取

### 6.3 修改事件处理函数

```javascript
// 重命名并修改 toggleTempDifficulty 函数
toggleDifficulty(e) {
  const { level } = e.currentTarget.dataset;
  let updateData = {};
  
  switch(level) {
    case '初级':
      updateData.difficultyBeginner = !this.data.difficultyBeginner;
      break;
    case '中级':
      updateData.difficultyIntermediate = !this.data.difficultyIntermediate;
      break;
    case '高级':
      updateData.difficultyAdvanced = !this.data.difficultyAdvanced;
      break;
    case '挑战级':
      updateData.difficultyChallenge = !this.data.difficultyChallenge;
      break;
    default:
      console.error('未知的难度等级:', level);
      return;
  }
  
  this.setData(updateData);
}
```

### 6.5 修改 `saveSettings` 方法

```javascript
saveSettings() {
  // 直接从 difficultyBeginner 等变量读取设置
  const { difficultyBeginner, difficultyIntermediate, difficultyAdvanced, difficultyChallenge, testDifficulty } = this.data;
  
  // 检查是否至少选择了一个难度
  const hasSelectedDifficulty = difficultyBeginner || difficultyIntermediate || difficultyAdvanced || difficultyChallenge;
  if (!hasSelectedDifficulty) {
    wx.showToast({
      title: '难度选择配置必须至少选择一个选项',
      icon: 'none',
      duration: 2000
    });
    return;
  }
  
  // 保存到本地存储
  wx.setStorageSync('dailyCharacterDifficulties', {
    difficultyBeginner,
    difficultyIntermediate,
    difficultyAdvanced,
    difficultyChallenge
  });
  
  // 保存测试难度到本地存储
  wx.setStorageSync('dailyCharacterTestDifficulty', testDifficulty);
  
  // 更新数据（如果需要）
  // 由于已经直接修改了 difficultyBeginner 等变量，这里可能不需要更新
  
  // 关闭设置窗口
  this.setData({
    settingVisible: false
  });
  
  // 重新过滤汉字
  this.filterCharacters();
  
  // 显示保存成功提示
  wx.showToast({
    title: '设置已保存',
    icon: 'success',
    duration: 1500
  });
}
```

通过这个方案，我们将移除 `tempDifficulties` 临时变量，完全采用直接操作实际设置变量的方式，简化设置流程，避免临时变量导致的不一致性，确保设置的正确读取和保存。
