# 每日一字应用字卡图像优化方案

## 1. 问题分析

* **现象**：保存时生成的字卡图像中，正确读音显示在字的下方，不够美观和易读

* **原因**：

  * 绘制汉字和正确读音的代码使用了相同的 X 坐标（画布中间）

  * 正确读音的 Y 坐标比汉字低，导致显示在下方

* **目标**：将正确读音从字的下方移动到字的右方，与首页字卡的显示类似，更易读、更美观

## 2. 解决方案

* **修改文件**：`/Users/joshua/Documents/GitHub/Chinesetraditional-miniprogram/subgames/daily-character/index.js`

* **修改思路**：

  1. 修改绘制汉字的位置，使其向左偏移
  2. 修改绘制正确读音的位置，使其向右偏移，并与汉字在同一行
  3. 调整字体大小和位置，确保整体美观
  4. 同时修改保存字卡和分享图片的代码

* **具体修改**：

  ### 2.1 修改保存字卡图像的代码

  * **文件位置**：`index.js` 中的 `saveCard` 方法

  * **修改内容**：

    1. 修改绘制汉字的 X 坐标，使其向左偏移
    2. 修改绘制正确读音的 X 坐标，使其向右偏移
    3. 确保汉字和正确读音在同一 Y 坐标

  ### 2.2 修改分享图片生成的代码

  * **文件位置**：`index.js` 中的 `generateShareImage` 方法

  * **修改内容**：

    1. 同样修改绘制汉字和正确读音的位置
    2. 确保分享图片的布局与保存字卡的布局一致

## 3. 实施步骤

### 3.1 修改保存字卡图像的代码

1. **找到绘制汉字的代码**：

   ```javascript
   ctx.fillText(todayCharacter.char, width / 2, frontTop + 150);
   ```

2. **找到绘制正确读音的代码**：

   ```javascript
   ctx.fillText(todayCharacter.correctPronunciation, width / 2, frontTop + 250);
   ```

3. **修改为**：

   ```javascript
   // 绘制汉字（向左偏移）
   ctx.fillText(todayCharacter.char, width / 2 - 100, frontTop + 150);

   // 绘制正确读音（向右偏移，与汉字同一行）
   ctx.fillText(todayCharacter.correctPronunciation, width / 2 + 100, frontTop + 150);
   ```

### 3.2 修改分享图片生成的代码

1. **找到绘制汉字的代码**：

   ```javascript
   ctx.fillText(todayCharacter.char, width / 2, 320);
   ```

2. **找到绘制正确读音的代码**：

   ```javascript
   ctx.fillText(todayCharacter.correctPronunciation, width / 2, 400);
   ```

3. **修改为**：

   ```javascript
   // 绘制汉字（向左偏移）
   ctx.fillText(todayCharacter.char, width / 2 - 120, 320);

   // 绘制正确读音（向右偏移，与汉字同一行）
   ctx.fillText(todayCharacter.correctPronunciation, width / 2 + 120, 320);
   ```

## 4. 预期效果

* 保存时生成的字卡图像中，正确读音显示在字的右方，与首页字卡的显示类似

* 字卡图像更易读、更美观

* 分享图片的布局与保存字卡的布局一致

## 5. 风险评估

* **低风险**：修改内容仅涉及图像绘制的位置调整，不影响核心功能

* **低风险**：保持了原有的数据结构和处理逻辑，仅调整了视觉呈现

* **无风险**：修改后的代码更符合用户预期，提高了应用的易用性和美观度

## 6. 实施代码

### 6.1 修改保存字卡图像的代码

```javascript
// 绘制汉字（向左偏移）
ctx.fillStyle = '#8B4513';
ctx.font = '160px sans-serif';
ctx.textAlign = 'center';
ctx.fillText(todayCharacter.char, width / 2 - 100, frontTop + 150);

// 绘制正确读音（向右偏移，与汉字同一行）
ctx.fillStyle = '#28a745';
ctx.font = '60px sans-serif';
ctx.textAlign = 'center';
ctx.fillText(todayCharacter.correctPronunciation, width / 2 + 100, frontTop + 150);
```

### 6.2 修改分享图片生成的代码

```javascript
// 绘制汉字（向左偏移）
ctx.fillStyle = '#8B4513';
ctx.font = '180px sans-serif';
ctx.textAlign = 'center';
ctx.fillText(todayCharacter.char, width / 2 - 120, 320);

// 绘制正确读音（向右偏移，与汉字同一行）
ctx.fillStyle = '#28a745';
ctx.font = '60px sans-serif';
ctx.textAlign = 'center';
ctx.fillText(todayCharacter.correctPronunciation, width / 2 + 120, 320);
```

通过这个方案，字卡图像中的正确读音将从字的下方移动到字的右方，与首页字卡的显示类似，更易读、更美观。
