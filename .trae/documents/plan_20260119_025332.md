# 每日一字应用设置功能优化方案

## 1. 问题分析

* **现象**：重新进入每日一字，进入设置页面，字卡难度显示所有都选中，但进入列表页，默认难度列表只显示了上次设置的难度的字。重新设置字卡难度后，再进入设置页面，显示正常。

* **原因**：

  1. 页面初始渲染时，`difficultyBeginner`等变量使用了硬编码的默认值`true`，导致设置页面显示所有难度都选中。
  2. `onLoad`方法中读取了本地存储并更新了这些变量，但WXML可能在`onLoad`执行之前就已经渲染完成。
  3. `onLoad`方法中仍然残留了设置`tempDifficulties`的代码，而该变量已被移除。
  4. 列表页重新读取了本地存储并应用设置，所以显示正确。

## 2. 解决方案

* **修改文件**：`/Users/joshua/Documents/GitHub/Chinesetraditional-miniprogram/subgames/daily-character/index.js`

* **修改思路**：

  1. 移除`onLoad`方法中设置`tempDifficulties`的残留代码。
  2. 确保页面初始加载时，`difficultyBeginner`等变量的初始值从本地存储中读取，而不是硬编码的`true`。
  3. 添加调试日志，便于跟踪设置读取和应用过程。

* **具体修改**：

  ### 2.1 移除`onLoad`方法中设置`tempDifficulties`的残留代码

  * **文件位置**：`index.js`中的`onLoad`方法

  * **修改内容**：

    ```javascript

    //   beginner: difficultyBeginner,
    //   intermediate: difficultyIntermediate,

    //   challenge: difficultyChallenge
    // },
    ```

  ### 2.2 确保页面初始加载时，`difficultyBeginner`等变量的初始值从本地存储中读取

  * **文件位置**：`index.js`中的`data`初始化

  * **修改内容**：

    1. 将`difficultyBeginner`等变量的初始值设置为`false`或`undefined`
    2. 在`onLoad`方法中读取本地存储并更新这些变量
    3. 添加调试日志，跟踪设置读取和应用过程

  ### 2.3 添加调试日志

  * **文件位置**：`index.js`中的`onLoad`方法和`openSettings`方法

  * **修改内容**：
