# 每日一字应用设置功能优化方案

## 1. 问题分析

* **现象**：重新进入每日一字，进入设置页面，字卡难度显示所有都选中，但进入列表页，默认难度列表只显示了上次设置的难度的字。

* **原因**：

  1. 在`onLoad`方法中，初始状态设置为`let difficultyBeginner = true`，导致如果本地存储中没有数据或数据格式不正确，所有难度都会保持为`true`。
  2. 虽然在`data`中设置了初始值为`false`，但`onLoad`方法会覆盖这些值。
  3. 当本地存储中没有数据或数据格式不正确时，会执行`else`分支，但`else`分支中没有更新`difficultyBeginner`等变量的值，导致它们保持初始的`true`值。

## 2. 解决方案

* **修改文件**：`/Users/joshua/Documents/GitHub/Chinesetraditional-miniprogram/subgames/daily-character/index.js`

* **修改思路**：

  1. 将`onLoad`方法中的初始状态设置为`false`，确保在没有本地存储时，所有难度默认不选中。
  2. 修改`else`分支，确保在没有本地存储时，也使用默认值`false`。
  3. 添加更多调试日志，跟踪每个步骤的变量值，便于问题定位。

* **具体修改**：

  ### 2.1 修改`onLoad`方法中的初始状态

  * 将`onLoad`方法中的初始状态从`true`改为`false`。

  * 确保在没有本地存储时，所有难度默认不选中。

  ### 2.2 修改`else`分支

  * 在`else`分支中，明确设置`difficultyBeginner`等变量的值为`false`。

  * 确保在没有本地存储时，也使用默认值`false`。

  ### 2.3 添加更多调试日志

  * 在`onLoad`方法的每个关键步骤添加调试日志。

  * 跟踪`difficultyBeginner`等变量的变化过程。

  * 跟踪`else`分支的执行情况。

## 6. 实施代码

### 6.1 修改`onLoad`方法中的初始状态

```javascript
// 初始状态：默认四个难度都不选中
let difficultyBeginner = false;
let difficultyIntermediate = false;
let difficultyAdvanced = false;
let difficultyChallenge = false;
```

### 6.2 修改`else`分支

```javascript
} else {
  // 无本地存储，使用默认值
  difficultyBeginner = false;
  difficultyIntermediate = false;
  difficultyAdvanced = false;
  difficultyChallenge = false;
  
  // 保存默认值到本地存储
  wx.setStorageSync('dailyCharacterDifficulties', {
    difficultyBeginner,
    difficultyIntermediate,
    difficultyAdvanced,
    difficultyChallenge
  });
}
```
