# 每日一字应用图标样式恢复方案

## 1. 问题分析

* **现象**：之前将图标字体大小和图标容器尺寸从42rpx减小到32rpx，现在需要恢复到原来的42rpx

* **原因**：用户反馈图标太小，需要恢复到原来的大小

## 2. 解决方案

* **修改文件**：`subgames/daily-character/index.wxss`

* **修改思路**：

  1. 找到`.secondary-icon`样式
  2. 将`font-size`从32rpx恢复到42rpx
  3. 将`width`和`height`从32rpx恢复到42rpx
  4. 移除可能添加的`overflow: hidden`属性（如果不需要）

* **具体修改**：

  ### 2.1 恢复图标样式

  * **文件位置**：`index.wxss`文件中

  * **修改内容**：

    1. 将`font-size`从32rpx恢复到42rpx
    2. 将`width`和`height`从32rpx恢复到42rpx
    3. 移除`overflow: hidden`属性

## 3. 实施步骤

### 3.1 恢复图标样式

1. 打开`index.wxss`文件
2. 找到`.secondary-icon`样式
3. 修改相关属性值，恢复到42rpx

### 3.2 验证修改效果

1. 重新编译并运行应用
2. 检查图标大小是否恢复到原来的42rpx
3. 确认所有图标显示正常

## 4. 预期效果

* 所有图标字体大小恢复到42rpx

* 所有图标容器尺寸恢复到42rpx

* 图标显示正常，大小合适

## 5. 风险评估

* **低风险**：仅修改CSS样式，不影响功能逻辑

* **低风险**：修改内容简单，容易恢复

* **无风险**：修改后的图标大小符合用户预期

## 6. 实施代码

```css
/* 修改前 */
.secondary-icon {
  font-size: 32rpx;
  color: rgba(255, 255, 255, 0.9);
  transition: all 0.3s ease;
  display: block;
  width: 32rpx;
  height: 32rpx;
  line-height: 32rpx;
  text-align: center;
  overflow: hidden;
}

/* 修改后 */
.secondary-icon {
  font-size: 42rpx;
  color: rgba(255, 255, 255, 0.9);
  transition: all 0.3s ease;
  display: block;
  width: 42rpx;
  height: 42rpx;
  line-height: 42rpx;
  text-align: center;
}
```

通过这个方案，我们将恢复图标的原始大小，确保图标显示正常，符合用户预期。
