# 词组读音校验方案

## 1. 问题分析

* **现象**：用户有一个"词组读音校验.csv"文件，每行包含字、读音、此读音的相关词组，需要校验每个词组中对应字的读音是否正确

* **挑战**：
  1. 汉字存在多音字现象，同一字在不同词组中可能有不同读音
  2. 需要准确判断每个词组中对应字的正确读音
  3. 大量词组需要自动化处理，提高效率
  4. 需要准确记录可能存在问题的词组

## 2. 解决方案

### 2.1 整体架构设计

1. **文件读取模块**：读取CSV文件内容
2. **读音校验模块**：校验每个词组中对应字的读音
3. **结果记录模块**：记录校验结果，特别是可能不正确的词组

### 2.2 技术选型

* **编程语言**：Node.js
* **CSV处理库**：csv-parser 或 fs+split 手动处理
* **读音校验**：使用pinyin库进行读音转换和校验
* **输出格式**：生成校验结果CSV文件

### 2.3 实现步骤

#### 2.3.1 环境准备

1. 安装Node.js环境
2. 创建项目目录和必要的文件
3. 安装所需依赖：
   ```bash
   npm install csv-parser pinyin
   ```

#### 2.3.2 代码实现

1. **读取CSV文件**：
   - 使用csv-parser库读取CSV文件
   - 解析每行数据，提取字、读音、相关词组

2. **读音校验逻辑**：
   - 对于每个词组，使用pinyin库获取其中对应字的所有可能读音
   - 判断该字在词组中的读音是否包含CSV中指定的读音
   - 如果不包含，标记为可疑词组

3. **结果记录**：
   - 将校验结果写入新的CSV文件
   - 包含原数据和校验结果
   - 对于可疑词组，明确标记

#### 2.3.3 核心代码逻辑

```javascript
const fs = require('fs');
const csv = require('csv-parser');
const pinyin = require('pinyin');

// 读取CSV文件
fs.createReadStream('词组读音校验.csv')
  .pipe(csv())
  .on('data', (row) => {
    const char = row['字'];
    const expectedPinyin = row['读音'];
    const phrases = row['相关词组'].split('、');
    
    // 存储可疑词组
    const suspiciousPhrases = [];
    
    // 校验每个词组
    phrases.forEach(phrase => {
      // 获取词组中每个字的所有可能读音
      const phrasePinyin = pinyin(phrase, {
        style: pinyin.STYLE_NORMAL,
        heteronym: true
      });
      
      // 找到当前字在词组中的位置
      const charIndex = phrase.indexOf(char);
      if (charIndex === -1) return;
      
      // 获取当前字在词组中的所有可能读音
      const possiblePinyins = phrasePinyin[charIndex];
      
      // 检查预期读音是否在可能读音中
      if (!possiblePinyins.includes(expectedPinyin)) {
        suspiciousPhrases.push(phrase);
      }
    });
    
    // 记录结果
    if (suspiciousPhrases.length > 0) {
      // 写入可疑词组
      const resultRow = {
        '字': char,
        '预期读音': expectedPinyin,
        '相关词组': row['相关词组'],
        '可疑词组': suspiciousPhrases.join('、'),
        '是否可疑': '是'
      };
      // 写入结果文件
      writeResult(resultRow);
    } else {
      // 写入正常结果
      const resultRow = {
        '字': char,
        '预期读音': expectedPinyin,
        '相关词组': row['相关词组'],
        '可疑词组': '',
        '是否可疑': '否'
      };
      // 写入结果文件
      writeResult(resultRow);
    }
  })
  .on('end', () => {
    console.log('校验完成');
  });
```

### 2.4 预期输出

* 生成一个新的CSV文件，包含以下字段：
  1. 字
  2. 预期读音
  3. 相关词组
  4. 可疑词组
  5. 是否可疑

* 对于每个字，记录所有相关词组中可能存在读音问题的词组

### 2.5 可能的问题和解决方案

1. **多音字问题**：
   - 解决方案：使用pinyin库的heteronym选项获取所有可能读音
   - 对于有多个可能读音的情况，只要预期读音在其中，就认为是正确的

2. **词组中包含多个相同字**：
   - 解决方案：遍历词组中所有相同字的位置，逐一校验

3. **CSV文件格式问题**：
   - 解决方案：在读取前检查文件格式，确保包含所需字段
   - 处理可能的编码问题

4. **pinyin库准确性问题**：
   - 解决方案：可以考虑使用多个读音库进行交叉验证
   - 对于有疑问的结果，标记为需要人工确认
